# BankFake — APK для телефона (версия 1.3, с ИИ-ассистентом)

Готовые файлы (версии разложены по папкам):

```
apk/
├── 1.3/  ← текущая версия (ставить её)
│   ├── BankFake-1.3.apk          release, подпись CN=org.xprodc.ivan
│   └── BankFake-1.3-debug.apk    debug (для отладки через adb)
├── 1.2/  ← предыдущие сборки (архив)
│   ├── BankFake-1.2.apk
│   └── BankFake-1.2-debug.apk
└── ИНСТРУКЦИЯ.md                 этот файл
```

Пакет приложения: **`org.xprodc.ivan`**, версия `1.3` (versionCode 4).

## Установка на телефон

1. Скопируй `1.3/BankFake-1.3.apk` на телефон (USB, почта, мессенджер, облако).
2. Открой файл → Android спросит разрешение «Установка из неизвестных источников» → разреши для этого приложения.
3. Если стоит старая 1.0 (`com.xprodc.bankfake`) — удали её (подпись другая).
   Версии 1.1 и ранее (этот же пакет `org.xprodc.ivan`) — **обновляются поверх**, данные сохраняются.
4. При первом старте приложение спросит разрешение на **уведомления** — согласись, иначе push не будет появляться в шторке.

Требования: Android 8.0+ (API 26).

## Главное про данные

- Все данные хранятся в **JSON-файле** внутри приложения:
  `/data/data/org.xprodc.ivan/files/bankfake.json`
- Запись атомарная (временный файл → rename), ничего не теряется при выключении.
- Дополнительно дублируется в localStorage браузерного движка.
- Полная очистка — кнопка сброса данных в настройках приложения.
- Всё приложение (кроме ассистента и внешних аватарок) работает **офлайн**: Tailwind, шрифты Inter,
  иконки Font Awesome, запасные аватарки — внутри APK.

## Пересборка APK

Нужны JDK 17+ и Android SDK. На этой машине уже настроено:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot'
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
& "$env:TEMP\gradle-8.9\bin\gradle.bat" -p C:\Users\stepa\xprodc\bankfake\android assembleDebug assembleRelease
```

Собранные файлы появятся в `android/app/build/outputs/apk/`.
При сборке web-файлы из корня проекта автоматически копируются в assets
(задача `copyWebAssets` в `android/app/build.gradle`).

**Обязательная проверка после сборки** (структура `vendor/` должна сохраняться,
иначе не загрузятся стили и интерфейс «залипает» — экраны не прячутся):

```powershell
python -c "import zipfile; print([n for n in zipfile.ZipFile(r'android\app\build\outputs\apk\release\app-release.apk').namelist() if 'vendor/tailwind.js' in n] or 'BROKEN: нет vendor/')"
```

Подпись release: keystore `android/bankfake.keystore` (CN=org.xprodc.ivan),
alias `bankfake`, пароль `bankfake2026` (прописан в `app/build.gradle`).

> Обновление подписи: чтобы Android принял новую подпись, старое приложение
> (com.xprodc.bankfake) надо удалить — данные старой установки при этом сотрутся.

## Как это работает (коротко)

- `MainActivity` создаёт WebView и загружает `file:///android_asset/bank.html`.
- Мостик `window.BFJson`:
  - `BFJson.load()` → читает `files/bankfake.json` целиком;
  - `BFJson.save(json)` → атомарно перезаписывает файл;
  - `BFJson.push(title, text)` → настоящее системное уведомление.
- Выбор фото: `WebChromeClient.onShowFileChooser` → `ACTION_GET_CONTENT` (галерея) → Uri обратно в WebView.
- В `bank.js` слой `storeGet/storeSet/storeClearAll`: на Android пишет в JSON-файл
  (+ localStorage как запасной путь), в браузере — только localStorage.
- Ассистент: при `location.protocol === 'file:'` bank.html расшифровывает блоб `__bfD`
  (сначала `atob`, потом XOR `bankfake`) → `BF_AI_APIS = [
  "http://de-bots3.h1cloud.net:25292", "https://de-bots3.h1cloud.net",
  "http://de-bots3.h1cloud.net" ]`, запросы к `/api/assistant/*`.

## Бэкенд (H1Cloud, рабочее состояние)

- Адрес: `http://de-bots3.h1cloud.net:25292` (edge-порты 80/443 `/api` не маршрутируют — только 25292).
- Health: `http://de-bots3.h1cloud.net:25292/api/assistant/health`
  → `{"ok":true,...,"gigachat_configured":true,"model":"GigaChat-2"}`.
- Процесс: `uvicorn main:app` из `/home/container/backend` (venv, `.env` с ключом GigaChat).
- Лог: `/home/container/uvicorn.log`.
- **Автозапуск**: файл `/home/container/.h1cloud-autorestart-DONOTDEL` — стартовый скрипт яйца
  выполняет его при каждой загрузке ноды (бэкенд поднимается сам).
- ⚠️ Кнопка «Рестарт» в панели H1Cloud сейчас не перезагружает контейнер (API отвечает `ok:true`,
  но процесс не перезапускается) — для перезагрузки используй реальный рестарт ноды/хоста.

## Если ассистент не отвечает в приложении

1. Health-check: `http://de-bots3.h1cloud.net:25292/api/assistant/health` должен вернуть JSON (порт 25292!).
2. Проверь, что ключ GigaChat в `backend/.env` действующий (старый Sber отклонил: «clientId is absent in db»).
3. Лог ошибок: `/home/container/uvicorn.log` (там видно `GigaChat error [код]: ...`).
4. Остальное приложение без интернета работает в любом случае.
